# Diploma Middle JavaScript Project

## Project setup

This project uses native JavaScript with ES6 modules and Webpack.

### Install dependencies

```bash
npm install
```

### Development build

```bash
npm run build
```

### Watch mode

```bash
npm run dev
```

### Production build

```bash
npm run build:production
```

After the build, Webpack creates `js/bundle.js` and `js/bundle.js.map`.

The project contains three HTML pages:

- `index.html`
- `balkony.html`
- `kuhni.html`

The existing Yandex Maps scripts in the HTML files are preserved.
